# 🧶 한코마을 (HankoVillage)

> **뜨개질의 단카운터·메모·도안 관리부터 커뮤니티까지, 하나의 앱에서 해결하는 뜨개인 전용 올인원 플랫폼**

---

## 👥 팀원 구성 및 역할 (Team & Roles)

| 이름 | 담당 역할 | 주요 담당 업무 |
| :--- | :--- | :--- |
| **정수아** | **인프라 담당** | Docker · DB · 스토리지 · 인증 API 구축 |
| **최수진** | **앱 개발 담당** | Kotlin 화면 · 비즈니스 로직 API 구현 (목업 데이터 화면 구성 후 실제 로직 연동) |

---

## 🎯 대상 사용자 및 시나리오

* **대상 사용자**:
  * **주 타깃**: 20~30대 뜨개질 취미 이용자
  * **보조 타깃**: 40대 이상 (쉬운 UI/UX로 접근성 확보)
  * **공통**: 뜨개질 이용자

---

## ✨ 주요 기능 (Key Features)

| 중요도 | 기능 | 상세 내용 |
| :---: | :--- | :--- |
| **최상** | **뜨개 커뮤니티** | 카테고리별 게시판, 댓글, 좋아요, 위치 기반 뜨개 카페 찾기 |
| **상** | **단수 카운터** | +/- 버튼으로 단수 기록, 다중 프로젝트 지원, 로그인 시 기기 간 동기화 |
| **상** | **도안 보관소** | 카드형 UI로 도안 저장·관리, 진행상태(예정/진행/완성) 추적 |
| **중** | **뜨개 메모** | 작업 중 특이사항을 사진과 함께 기록 |
| **중** | **프로필** | 완성작 갤러리, 내 활동 내역 관리 |

---

## 🤝 개발 협업 구조

* **API 스펙 공유**: Swagger 문서를 매개로 주 1~2회 정기 싱크 후 통합 테스트 진행
* **통합 테스트 **: 
  * 정수아: Docker/DB/스토리지/모니터링 인프라 구축, 인증·파일업로드 API
  * 최수진: Kotlin 앱 화면 전체, 카운터·메모·도안·커뮤니티·프로필 로직 API
* **앱 개발 작업 순서**: 목업 데이터로 화면 먼저 구성 ➔ 실제 로직 연동 (매주 목업/실연동 상태 구분해서 공유)
